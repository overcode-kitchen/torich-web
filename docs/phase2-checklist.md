## 1. 기능 존치 / 삭제 판정 — **2026-08-24 대부분 확정**

판정 기준은 하나 — **"1억 모으기를 돕는가."**

- [x] **목적(goals)** — **삭제.** 목표가 1억 하나면 계층이 사라진다. **태그로도 남기지 않는다**
- [x] **목적 프리셋** — **삭제.** 목적에 종속
- [x] **토리 키우기** — **삭제.** 진입 경로가 없어 이미 없는 기능. 브랜드 스토리 파일과 **분리해서** 지운다
- [x] **소급 기록** — **존치.** 과거 회차를 넣을 수 있게 한다
- [x] **알림 7종** — **v2.0.0에서 손대지 않는다.** 문구만 1억 기준으로 고친다
- [x] **FAQ · 브랜드 스토리** — **존치 · 내용 교체.** 지금 내용이 목적·3유형 기준이라 재작성이 필요하다
- [x] **`/design-system`** — **존치.** 컴포넌트·토큰 점검용으로 실제로 쓴다
- [x] **통계 23섹션** — **`/detail` 3섹션으로 축소.** 단 재작성이라 **순서는 맨 뒤** (§4에 종속)
- [ ] **납입 연기** — 논의 중(삭제 유력). 마감일이 없어 "빠뜨림"이 사라지고 **소급 존치가 그 역할을 대체**한다.
      지우려면 **연속 기록을 무엇으로 바꿀지**(연속 → 누적) 같이 정한다
- [ ] `/notifications?demo=1` — 개발용 경로 정리

### 목적 삭제로 새로 생긴 결정

- [ ] 목적별 **마감일 · 목표금액**을 버리는가 (버리는 쪽이 유력 — 1억엔 목적별 마감일이 없다)
- [ ] 목적이 **여러 개인 사용자**의 항목을 하나의 1억으로 합치는 규칙
- [ ] **FAQ 재작성**을 9월 카피 작업에 넣는다 (§7)
- 참고: `records.goal_id`는 **컬럼만 남기고 화면에서 안 쓴다** (스키마 규칙상 삭제 금지)

## 2. 입력 플로우 (8/28 ~ 9/1)

**8/24 확정**

- [x] **유형(투자/예적금/현금) 질문 삭제** — 입력 규칙 하나로 통일
- [x] **종목 검색 · 주수 존치** — ETF는 **주 단위로 사는 물건**이라 금액만으로는 기억이 안 된다
- [x] **금리 · 만기일은 선택 필드** — 안 물어도 되게만 만들고 지우지는 않는다

**남은 것**

- [ ] **⭐ 1억 카운터를 무엇으로 세는가** ← 제일 큰 결정
      → 논의 중인 안: **3층 분리** — 카운터는 *지금 가치*(종목 있으면 `주수 × 현재가`, 없으면 넣은 금액),
        그 아래 *넣은 돈* 병기, **축하 · 도토리 · 연속은 납입 행위만** 본다(시세와 분리).
        시세와 축하를 묶으면 **주가 빠진 달에 넣어도 아무 일이 안 일어난다**
      → 참고: 시세 인프라는 **이미 있다** (`app/api/stock/route.ts` yahoo-finance2,
        `app/utils/stock-price-fetcher.ts` 실시간→7일 캐시→null, `payment_history.captured_price`)
- [ ] **⭐ 1억에 "목표 시점"을 선택으로 둘 것인가**
      → 논의 중인 안: **마감일이 아니라 페이스 계산기의 입력값.**
        `매달 얼마` ↔ `언제까지` 는 같은 식의 양변이라 **둘 중 하나만 받으면 나머지가 나온다.**
        D-day · 빨간 미달 표시는 두지 않고 **"5개월 밀렸어요"까지만** 말한다
- [ ] **미국 종목 환율 시점** — ⓐ 체결 시점 환율을 `payment_history`에 같이 저장 ⓑ 조회 시점 환율로 매번 환산
      → ⓐ가 유력. ⓑ는 **환율만 움직여도 과거 기록이 계속 바뀐다**. 코드에 환율 조회가 **아직 없다**
- [ ] 만기일이 **있는 항목과 없는 항목**을 같은 폼에서 어떻게 받는가
- [ ] 이미 넣던 항목의 **과거 회차를 어디까지** 받을 것인가 (소급 존치 확정 → 범위만 정한다)
- [ ] 주수 · 시장이 붙어도 **"필수 4개"가 안 깨지는지** 검증
- [ ] 적립 항목 1개 추가에 드는 **동작 수를 숫자로 확정** (지금 안: 타이핑 2 + 탭 4)
