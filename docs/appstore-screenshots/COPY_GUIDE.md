# 앱스토어 스크린샷 최신화 가이드

> 목적: 스토어 스크린샷의 메시지를 **"투자 리마인더" → "목적을 정하고, 그 목적에 맞는 적립을 꾸준히"** 컨셉으로 최신화한다.
> 레이아웃(패널 수·순서)은 그대로 두고, **헤드라인 텍스트 + 앱 화면 이미지만 교체**한다.

## 배경 — 무엇이 바뀌었나

앱이 **투자 중심 → 목적(goal) 중심 + 목적에 맞는 적립(saving)** 으로 재구성됐다.

- 홈이 평면 "투자 목록"에서 **목적 그룹 카드**(목적 아래에 적립 항목들이 묶이고 진행률 표시)로 개편됨.
- 온보딩·목적 생성·통계가 "목적/적립/이행/모으기" 용어로 이전됨. (`app/constants/onboarding.ts`가 신규 브랜드 보이스의 기준)
- **삭제된 화면/개념**: "다가오는 투자" 카드, "내 투자 목록" 평면 리스트, "랑쥐씨, 어떤 꿈을 꾸고 계신가요?" 형태의 옛 투자 추가 화면. → 스크린샷에서 이 개념들을 그대로 재현하면 **현재 앱과 불일치**하므로 새 화면으로 촬영해야 함.

## 파일 위치 & 워크플로우

- 원본 앱 스크린샷(프레임 없는 기기 캡처): `docs/appstore-screenshots/01-onboarding.png` ~ `05-add.png` — **현재 모두 옛 용어/옛 레이아웃이라 재촬영 필요**.
- 헤드라인이 얹힌 완성 스토어 이미지: 저장소에 소스 없음(외부 디자인 툴에서 제작). → **외부 툴에서 헤드라인 텍스트 + 아래 앱 이미지만 교체**.

## 패널별 교체안 (old → new)

각 패널: **① 헤드라인 카피** + **② 아래에 넣을 앱 화면**.

### 패널 A — 앱 아이콘 / 피처 그래픽 (알림 목록 목업)
- 헤드라인(서브카피)
  - old: `티끌이 스쳐 지나가지 않게, / 나만의 돈 모으기 리마인더`
  - **new: `티끌이 스쳐 지나가지 않게, / 목적을 정하고 꾸준히 모으는 리마인더`**
  - ("티끌이 스쳐 지나가지 않게"는 토리치(도토리+리치) 브랜드 문구라 유지, 둘째 줄만 '목적' 리드로 교체)
- 앱 화면: 알림 카드 목업 유지. 카드 문구(삼성전자 매수일·주택청약 납입일·비상금 저축일·S&P500 매수)는 투자+저축+현금을 아우르므로 **'적립' 컨셉과 그대로 부합** — 그대로 둬도 됨.

### 패널 1 — 홈 (목적 그룹)
- 헤드라인
  - old: `투자를 잘 몰라도, / 목적부터 정하고 '꾸준함'을 만들어요`
  - **new: `무엇을 위해 모을지 정하면, / 그 목적에 맞춰 '꾸준함'을 만들어요`**
  - (대안: `투자를 잘 몰라도 괜찮아요, / 목적부터 정하면 모으기가 쉬워져요`)
- 앱 화면: **새 홈 = 목적 그룹 카드**(목적명 + 그 아래 적립 항목 + 진행률, 하단 `목적 만들기` CTA). ⚠️ 옛 "다가오는 투자 / 투자 목록 추가하기 / 내 투자 목록"이 보이는 현재 `02-home.png`는 폐기.

### 패널 2 — 이번 달 적립 체크
- 헤드라인
  - old: `다가오는 투자날 / 한 번에 정리해 드릴게요`
  - **new: `이번 달 넣을 적립, / 목적별로 한 번에 챙겨 드릴게요`**
  - (온보딩 step2 "이번 달 넣을 적립, 한눈에 체크"와 톤 일치)
- 앱 화면: 목적 그룹에서 이번 달 적립 항목을 체크리스트처럼 `완료하기`로 챙기는 상태. ("다가오는 투자" 벨 화면은 삭제됨)

### 패널 3 — 캘린더
- 헤드라인
  - old: `이번 달 언제 넣어야 할지, / 캘린더로 한눈에 확인하세요`
  - **new: `이번 달 어떤 적립을 언제 넣을지, / 캘린더로 한눈에 확인하세요`** (거의 유지, '적립'만 명시)
- 앱 화면: 캘린더 화면(`03-calendar.png`) — 레이아웃 변화 없음. 최신 캡처만 교체.

### 패널 4 — 목적·적립 설정
- 헤드라인
  - old: `종목·기간·금액만 정하면, / 매달 얼마를 넣을지 계산해 드려요`
  - **new: `목적·금액·기간만 정하면, / 매달 얼마씩 모을지 계산해 드려요`**
  - ('종목'은 이제 투자뿐 아니라 예적금·현금도 담으므로 '목적'으로 대체)
- 앱 화면: **새 추가 플로우**(`어떤 목적을 만들까요?` → `어디에 모을까요?`(투자/예적금/현금) → `매달 얼마를 모을까요?` → `언제 모을까요?`). ⚠️ 옛 "랑쥐씨, 어떤 꿈을 꾸고 계신가요?" 화면(`05-add.png`)은 폐기.

### 패널 5 — 통계 결과
- 헤드라인
  - old: `꾸준히 모은 결과를 / 예상 자산·수익 차트로 보여드릴게요`
  - **new: `꾸준히 모은 결과가 / 목적에 얼마나 가까워졌는지 보여드릴게요`**
  - (대안: `꾸준히 모은 결과를, / 목적 진척과 예상 자산으로 보여드릴게요` — 예상 자산 차트를 계속 노출할 경우)
- 앱 화면: 통계 화면. 새 통계는 `이번 달 이행률`·`목적 진척`·`지금까지 모은 원금`이 메인. 예상 자산/복리 차트도 유지되므로 어느 쪽을 강조할지에 맞춰 캡처.

## 주의 / 후속 검토

- **앱 자체엔 '투자' 잔존**: 홈 `이번 달 투자금액`(`MonthlyAmountCard.tsx`), 앱 슬로건 `매달 투자, 까먹지 않게`(`app/layout.tsx`), 랜딩 카피가 아직 옛 용어다. **스크린샷을 목업으로 직접 제작하면 텍스트를 원하는 대로 넣을 수 있지만, 실제 앱을 캡처하면 이 부분이 '적립'이 아니라 '투자'로 보인다** — 목업 텍스트와 실제 앱이 어긋나지 않도록 유의.
- 스토어 설명 텍스트(App Store Connect의 프로모션 문구/설명)도 같은 '목적·적립' 톤으로 함께 손보면 스크린샷과 일관됨. (현재 `app/layout.tsx` 메타데이터는 "적립식 투자" 중심)
- 브랜드 보이스 원본이 필요하면 `app/constants/onboarding.ts`를 기준으로 삼는다.
