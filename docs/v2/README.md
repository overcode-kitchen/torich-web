# 토리치 v2.0.0 리뉴얼

> [!abstract] 한 줄로
> **"매달 투자, 까먹지 않게" 앱을 "1억 모으기" 앱으로 다시 만든다.**

## 지금 어디까지 왔나

```
Phase 0  준비                      8/19 ~ 8/20   ✅
Phase 1  컨셉 확정 — "1억 모으기"    8/19 ~ 8/20   ✅
Phase 2  기능 판정 · 플로우 재설계   8/25 ~ 8/31   ← 판정·스키마 확정 완료, 화면 설계 진행 중
Phase 2.5 스키마 + 삭제             9/1  ~ 9/6
Phase 3  구현                       9/7  ~ 9/21
Phase 4  ASO + 심사 제출            9/22 ~ 9/30
```

**2026-08-25 회의로 정해진 것** — ① 타겟 A·B 동시(온보딩 분기) ② B는 스크린샷 스킵, 계획만으로 홈이 돈다
③ 자동 채움이 기본(사용자가 누르는 체크를 없앤다) ④ 카운터는 **원금 2층** ⑤ 실시간 카운트업을 v2 범위로
⑥ 입력은 은행 적금 상세 페이지처럼 위→아래 ⑦ 적립 항목 상세 화면 삭제 ⑧ 스키마 변경 4건 확정

> [!warning] **MVP를 더 좁혔다** — **ETF(종목·주수·시장) · 기록 탭(달력) · 소급 기록을 뺀다**
> 탭은 **2개**(홈 · 설정)가 되고, 입력 단위는 **"원" 하나**가 된다.
> **내부 테스트로 MVP를 먼저 써보고 추가 기능을 고려한다** — 늘리는 판단은 쓰고 나서 한다.

## 규칙

- **일정을 두 곳에 적지 않는다.** 01의 §10은 요약이고, 정본은 **02**다. 어긋나면 02가 맞다.
- **결정은 03에만 `[x]`로 남긴다.** 다른 문서에 "확정"이라고 써 있어도 03이 기준이다.
- **스키마는 함부로 확정하지 않는다.** 운영 앱에 구버전이 살아 있어 스키마 변경 = Breaking Change다. ([../../CLAUDE.md](../../CLAUDE.md))
