# 투자 상태 요약 카드 개선 (이슈 #27)

통계 페이지 하단 **"투자 상태 요약"** 카드(`ModeBreakdownSection`)를 재구성했다.
검토용 정리 문서. 실제 화면은 `/stats` 페이지 하단에서 확인.

## 왜 고쳤나 — 기존 카드의 문제

| 기존 표시 | 문제 |
|---|---|
| 목표형 "진행률 가장 낮음 · 삼성전자 0%" | `진행률 = 경과개월 ÷ 총개월`, **순수 시간경과율**. 0%는 "문제"가 아니라 "막 시작"일 뿐. 있는 납입 데이터를 안 쓰고 오해를 만듦 |
| 목표형 "가장 빠른 만기 · D-362" | 1년도 더 남았는데 "가장 빠른"이라 강조. 임박도 액션도 아님 |
| 적립형 "가장 오래 쌓음 · 2개월" | 실제 연속 납입이 아니라 시작일 경과 개월(허수) |
| **게이트**: 목표형+적립형 둘 다 있을 때만 노출 | 한 종류만 쓰는 다수 사용자에겐 카드가 아예 안 보임 |

핵심 진단: **"상태 요약"인데 상태 판단(순조/미납)이 없고, 대표값 하나만 뽑아 나머지 항목이 안 보였다.**

## 방향 — "설명"보다 "판단", 대표값보다 "항목별"

- **A(안심·격려) 기본 + B(할 일 알림) 절충**: 통계 톤을 지키되, 미납·예정 같은 액션 신호는 배지로만.
- **대표값 뽑기 폐기 → 항목마다 한 줄 + 이번 달 납입 상태 배지.**
- 발견: 납입 완료는 **사용자가 직접 체크한 기록**(`payment_history`)이라 진짜 상태 판정이 가능. 목표형도 동일 데이터가 있는데 카드만 안 썼던 것.

## 바뀐 화면

각 투자 항목을 한 줄씩, **급한 순 정렬**(미납 → 예정 → 완료 → 예정없음)로 나열하고 각 줄에 배지를 단다.

```
투자 상태 요약

🎯 목표형 투자 2개              이번 달 1/2 챙김
   삼성전자        3/24회차     ⚠️ 15일 미납
   애플            5/12회차     ✅ 완료

🔥 적립형 투자 3개              이번 달 0/2 챙김
   적금            8회 납입     ⚠️ 5일 미납
   ETF 적립        2회 납입     🕐 25일 예정
   비트코인                     예정 없음
```

### 배지 4종 (이번 달 납입 상태)
- **✅ 완료**(초록) — 이번 달 예정분을 다 냄
- **🕐 N일 예정**(중립) — 아직 예정일 전, 곧 낼 차례
- **⚠️ N일 미납**(빨강) — 예정일이 지났는데 안 냄 ← 유일하게 색으로 강조하는 액션 신호
- **예정 없음**(회색) — 이번 달 예정 없음 또는 미룸

### 오른쪽 보조 지표
- **목표형: `N/M회차`** — 만기까지 총 개월(M) 대비 **실제 납입한 개월(N)**. 시간% 완전 대체 → "완주까지 실제로 얼마나 왔나".
- **적립형: `N회 납입`** — 만기가 없어 누적 납입 개월 수. 0이면 숨김.

### 게이트 제거
한 종류만 있어도 그 종류 블록을 노출.

## 계산 로직 (`useStatsCalculations.ts`)

- **이번 달 상태**: `getPaymentEventsForMonth`로 이번 달 예정 회차 생성 → `isPaymentCompleted`로 완료 판정. 미룬 회차는 제외. 미완료 중 가장 이른 날이 오늘 이전이면 `미납`, 이후면 `예정`.
- **완료 개월수(N)**: `completedPayments`(자동, 일 단위) + `retroactivePayments`(소급, 월 단위)를 **월 단위로 합쳐(`YYYY-MM`) 중복 제거**한 개수.
- **총 개월수(M, 목표형)**: `period_years × 12`.

### ⚠️ 확인 필요한 설계 결정 하나
**"N/M회차"는 월 단위로 센다.** 자동납입은 일 단위, 소급납입은 월 단위(`YYYY-MM-01`)라 스케일을 맞추려 월로 통일했다.
- 한 달에 **한 번** 넣는 항목(대부분) → **정확**.
- 한 달에 **두 번**(`investment_days`가 2개) 넣는 항목 → 실제론 "개월"인데 라벨은 "회차"라 살짝 어긋남.
- **결정 대기**: 라벨을 `회차`로 둘지 `개월`로 바꿀지 알려주면 반영.
